事件源 flow.EventSink

OnRunStart(RunInfo) → run 头部 + 进度条归零
OnPhase(runID,title,detail) → 新增 phase 分组
OnAgentStart(runID,AgentEvent) → 新增 agent 行，状态 running
OnAgentDone(runID,AgentEvent) → 更新为 done/failed
OnLog(runID,level,msg) → 追加日志流
OnRunDone(runID,result,err) → run 终态 + 回写主对话

核心结构体 internal/flow/types.go

RunInfo{RunID, Name, Meta} → run 头部
Meta{Name, Description, Phases[]} → 标题/描述/分组
Phase{Title, Detail} → phase 标题与说明
AgentEvent{ID, Label, Phase, Status, Tokens, Detail, Err} → agent 行
AgentSpec{AgentType} → explore/general/coordinator 标签
run{sema(16), agentTotal(1000), depth} → caps 预算条

状态色 §4

running 橙色脉冲 / accent
done 绿色 / success-fg
failed 红色 / destructive
pending 灰色 / muted
stopped 黄色 / warning
