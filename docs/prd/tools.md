# 工具系统 V2 产品需求文档 (PRD)

> 基于 jcode 与 Claude Code 对比分析，定义工具系统下一代演进方向。

---

## 1. 背景与目标

### 1.1 背景

jcode 是基于 Eino 框架 + BubbleTea TUI 的 Go CLI 编码助手。当前工具系统提供了基础的文件编辑、命令执行、搜索、任务管理和 MCP 集成能力，支持本地与 SSH 远程操作。

通过与 Claude Code 的深度对比分析，我们发现当前工具系统在以下方面存在显著差距：

- **Edit/Read/Write**：缺少冲突检测、结构化 diff、多编辑、编码感知
- **Ask User**：仅支持单问题单选，缺乏批量提问、选项预览、多选
- **MCP**：仅实现工具发现，缺少 OAuth 认证、资源发现、重连机制
- **Grep**：单一输出模式，无上下文行、分页、LSP 集成
- **Todo**：纯内存存储，无磁盘持久化、依赖关系、主动监视
- **Execute**：缺少自适应后台化、流式进度、Stall 检测、REPL

### 1.2 目标

将 jcode 工具系统提升至生产级水平，在保持 Go CLI + SSH 远程核心优势的同时，补齐关键能力短板：

1. **可靠性**：冲突检测、重连机制、持久化存储确保操作安全
2. **效率**：多编辑、批量提问、分页搜索减少工具调用轮次
3. **智能化**：自适应后台化、Stall 检测、主动监视提升自动化程度
4. **可扩展性**：MCP 资源发现、动态连接、OAuth 认证支持第三方生态

### 1.3 范围

- **包含**：Edit/Read/Write、Ask User、MCP、Grep、Todo、Execute 六大工具类别
- **不包含**：TUI 界面重构、Session 系统改造、Agent 核心循环变更

## 3. 功能需求

### 3.1 P0 — 核心必做

#### 3.1.1 Edit 冲突检测

- 记录文件 mtime + content hash，写入前校验
- 冲突时返回错误信息，由 Agent 决定重读或强制覆写
- 适用于 Edit 和 Write 工具

#### 3.1.2 Edit 多编辑支持

- 支持一次调用传入多组 `(old_string, new_string)` 替换
- 按从上到下顺序应用，自动调整行偏移
- 原子性：任一替换失败则全部回滚

#### 3.1.3 Read 文件大小限制

- 默认上限 10MB，可配置
- 超限返回前 N 行 + 总行数信息
- 二进制检测：magic bytes + 扩展名联合判断

#### 3.1.4 Ask User 选项描述

- options 扩展 `description` 字段
- TUI 中显示 label + description 两行
- 保持向后兼容（description 可选）

#### 3.1.5 MCP OAuth 认证

- 支持 OAuth2 授权码流程（PKCE）
- 检测 401 响应自动触发认证流
- Token 安全存储（keychain 或加密文件）
- Token 过期自动刷新

#### 3.1.6 MCP 自动重连

- 连接断开后指数退避重连（1s → 30s，最多 5 次）
- 重连成功后重新初始化工具列表
- 重连状态在 TUI 中可见

#### 3.1.7 Grep 上下文行

- 新增 `before_context` / `after_context` / `context` 参数
- 映射到 ripgrep -B/-A/-C 参数
- 默认值 0（兼容现有行为）

#### 3.1.8 Todo 磁盘持久化

- 任务列表序列化为 JSON 写入 `~/.jcoding/todos/<session_id>.json`
- 启动时加载、变更时写入
- Session resume 时自动恢复任务状态

#### 3.1.9 Todo 增量更新 API

- 新增 `add_todo` / `update_todo` / `remove_todo` 操作
- 保留 `todowrite` 全量替换作为兼容
- 减少 Agent 构造完整列表的开销

#### 3.1.10 Execute 自适应后台化

- 前台命令超过 `BLOCKING_BUDGET_MS`（默认 15s）自动转后台
- 返回任务 ID + 已收集输出摘要
- Agent 可通过 `check_background` 后续查询

#### 3.1.11 Execute 流式进度

- 前台执行期间通过 channel 流式返回输出片段
- TUI 实时显示命令输出
- 超时或完成时返回完整结果

### 3.2 P1 — 高价值增强

#### 3.2.1 Edit 结构化 Diff 输出

- 编辑成功后返回 unified diff 格式
- 包含修改行数、文件路径、修改摘要
- 便于 Agent 确认修改正确性

#### 3.2.2 Edit 编码检测

- 读取时自动检测 UTF-8 / UTF-16 / GBK
- 写入时保持原始编码
- 不支持的编码返回明确错误

#### 3.2.3 Edit 二进制文件检测

- magic bytes 检查（前 512 字节）+ 扩展名白名单
- 二进制文件拒绝文本编辑操作
- 返回文件类型信息

#### 3.2.4 Ask User 批量提问

- 支持一次传入 1-4 个问题
- TUI 逐个展示或列表展示
- 返回结构化多答案

#### 3.2.5 Ask User 多选模式

- 新增 `multi_select` 参数
- TUI 使用复选框样式
- 返回选中项数组

#### 3.2.6 MCP 资源发现与读取

- 实现 `resources/list` 和 `resources/read`
- 新增 `mcp_list_resources` 和 `mcp_read_resource` 工具
- 文本/二进制自动处理

#### 3.2.7 MCP 动态连接管理

- 运行时新增 `mcp_connect` / `mcp_disconnect` 工具
- 热更新工具列表（无需重启）
- TUI 状态栏显示已连接服务器数

#### 3.2.8 MCP 能力检测

- 根据服务器 Capabilities 动态启用/禁用功能
- 不支持的能力优雅降级
- 日志记录能力协商结果

#### 3.2.9 Grep 多输出模式

- `output_mode`: `content`（默认）| `files` | `count`
- `files` 模式仅返回匹配的文件列表
- `count` 模式返回各文件匹配数

#### 3.2.10 Grep 分页支持

- 新增 `offset` 参数，配合现有 `max_results`
- 返回 `total_matches` 总数
- 便于 Agent 决定是否加载更多

#### 3.2.11 Grep 文件查找工具

- 新增独立 `glob` 工具
- 按文件名模式查找（不搜索内容）
- 支持递归、深度限制

#### 3.2.12 Todo 依赖关系

- TodoItem 新增 `blocked_by` 字段（ID 数组）
- 验证：被阻塞任务不可设为 in_progress
- 被依赖任务完成时提醒 Agent

#### 3.2.13 Todo 主动监视

- 基于 fsnotify 监听任务文件变化（多会话场景）
- 变更事件注入 Agent 上下文
- 防抖合并（50ms 窗口）

#### 3.2.14 Execute Stall 检测

- 45 秒无新输出触发 Stall 告警
- 注入提示："命令可能等待输入或卡住"
- Agent 可选择终止或发送输入

#### 3.2.15 Execute 输出持久化

- 后台任务输出写入 `~/.jcoding/tasks/<task_id>.log`
- 支持大输出（上限 64MB）
- 内存中仅保留尾部摘要

#### 3.2.16 Execute Sleep 检测

- 正则检测 `sleep \d+` 模式
- 超过阈值（默认 30s）时告警
- 可配置白名单

## 4. 非功能需求

### 4.1 性能

| 指标 | 要求 |
|------|------|
| 文件编辑延迟 | 单次编辑 < 100ms（本地），< 500ms（SSH） |
| Grep 搜索 | 10万行项目 < 2s |
| MCP 重连 | 首次重连 < 2s |
| 后台任务启动 | < 50ms 返回任务 ID |
| Todo 持久化 | 写入 < 10ms |

### 4.2 可靠性

- 文件操作原子性：多编辑全成功或全回滚
- MCP 连接断开不影响内置工具使用
- 后台任务 panic 不崩溃主进程
- 磁盘持久化写入失败降级为内存模式

### 4.3 兼容性

- 现有工具参数完全向后兼容
- 新增参数均有默认值
- 新增工具不影响现有工具注册
- SSH 远程模式同步支持所有增强

### 4.4 安全性

- OAuth Token 不明文存储
- MCP 工具执行需审批机制
- 文件操作路径规范化（防穿越）
- 后台任务输出不泄露环境变量

### 4.5 可观测性

- 所有工具调用记录到 `~/.jcoding/debug.log`
- MCP 连接状态变更记录
- 后台任务生命周期事件
- 冲突检测命中率统计

## 5. 成功指标

| 指标 | 当前基线 | V2 目标 |
|------|---------|--------|
| 工具调用失败率（冲突/编码错误） | 未跟踪 | < 1% |
| 平均编辑调用次数/单一修改任务 | ~3次（分多次调用） | ~1.5次（多编辑合并） |
| MCP 连接成功率 | 首次成功或放弃 | > 99%（含自动重连） |
| 后台任务超时丢失率 | ~10%（内存截断） | < 0.5%（磁盘持久化） |
| 用户交互轮次/复杂问题收集 | 3-5 轮 | 1-2 轮（批量提问） |
| Grep 搜索满足率（一次获取足够信息） | ~60% | > 85%（上下文+分页） |
| Todo 任务恢复率（会话重启后） | 0%（内存丢失） | 100%（磁盘持久化） |
