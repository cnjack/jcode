# Tools V2 验收标准

## 概述

本文档定义 jcode Tools V2 各模块的验收标准，每个标准包含：功能需求、测试用例、性能指标、兼容性要求。

---

## 1. Storage Layer — 存储层

### 1.1 StorageManager

| 编号 | 验收项 | 标准 | 验证方法 |
|------|--------|------|---------|
| S-01 | 目录结构创建 | `NewStorageManager()` 后 file-history, tool-results, todos, plans, tasks, oauth 目录均存在 | 单元测试 |
| S-02 | 目录权限 | 所有 storage 子目录权限为 0700 | `stat` 验证 |
| S-03 | 文件写入权限 | 敏感文件 (OAuth, todos) 权限为 0600 | `stat` 验证 |
| S-04 | Close 刷入 | `Close()` 后所有待写入数据已落盘 | 写入后 Close → ReadFile 验证 |

### 1.2 WriteQueue

| 编号 | 验收项 | 标准 | 验证方法 |
|------|--------|------|---------|
| S-05 | 异步写入 | `WriteAsync` 不阻塞调用方 | 计时验证 <1ms |
| S-06 | 批量合并 | 100ms 窗口内多次写入合并为一次 I/O | mock fs 验证调用次数 |
| S-07 | DrainSync | `DrainSync()` 后所有队列清空 | 检查 entries map 为空 |
| S-08 | 并发安全 | 100 goroutine 并发 Enqueue 不 panic | `go test -race` |
| S-09 | 追加写入 | `Append=true` 的条目正确追加而非覆写 | 多次追加后验证内容 |

### 1.3 FileTracker

| 编号 | 验收项 | 标准 | 验证方法 |
|------|--------|------|---------|
| S-10 | 读取追踪 | `TrackRead()` 后 tracked map 包含文件信息 | 单元测试 |
| S-11 | 冲突检测-无变更 | 文件未修改时 `CheckConflict()` 返回 `ConflictNone` | 读取后立即检查 |

| S-17 | 最大快照数 | 超过100个快照后淘汰最老的 | 创建101个快照验证 |

## 9. 全局验收标准

### 9.1 兼容性

| 编号 | 验收项 | 标准 |
|------|--------|------|
| GL-01 | V1 API 兼容 | 所有现有工具调用格式不变依然正常工作 |
| GL-02 | Session 兼容 | V1 session JSONL 可被 V2 正确加载 |
| GL-03 | Config 兼容 | 现有 config.json 格式向后兼容 |
| GL-04 | SSH 兼容 | 所有 V2 增强在 SSH 模式下降级正常（FileTracker 回退到无冲突检测） |

### 9.2 性能

| 编号 | 验收项 | 标准 |
|------|--------|------|
| PF-01 | 启动时间 | V2 增加的启动开销 <100ms |

| PF-04 | FileTracker 开销 | 1000 个 tracked 文件内存 <10MB |

### 9.3 安全

| 编号 | 验收项 | 标准 |
