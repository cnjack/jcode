jcode

Your AI Coding Companion.

Think it. Code it.

An intelligent coding agent that lives in your terminal. Describe tasks in plain language — jcode reads your codebase, writes surgical edits, runs commands, and reports every step. No black boxes.

Get started Features

Why jcode?

   
No black boxes Every tool call is visible. Approve or reject edits before they happen.
Works anywhere Local machine, remote servers over SSH — same experience, zero config friction.
Parallel agents Spawn a team of AI teammates that work simultaneously on different tasks.
Plan before you act Plan Mode lets the agent explore read-only and present a plan for your approval.
Bring your own model Any OpenAI-compatible API. Switch models mid-session with one keystroke.
