02 — Desktop App

Native desktop, same agent

jcode ships a native desktop app built with Tauri. It wraps the same web UI from jcode web in a real OS window and adds native system integration.

  • Native OS notifications and system tray
  • Close-to-tray keeps agents running in the background
  • Global shortcut ⌘/⊞ + Shift + J toggles the window
  • Single instance · window-state memory · native folder picker
  • Loopback-only sidecar with cross-origin protection

03 — CLI

A command line for every workflow

Start the interactive TUI, launch the web UI, run a one-shot prompt, or expose a headless JSON-RPC server for editor integrations.

  • jcode — interactive TUI
  • jcode web — browser UI
  • jcode -p "task" — one-shot mode
  • jcode acp — headless JSON-RPC (ACP)
  • jcode doctor — verify setup
